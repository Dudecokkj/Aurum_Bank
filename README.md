**Descrição para o README (parágrafo):**
> O **Aurum Bank** é um projeto acadêmico (A3 de Banco de Dados) que modela e implementa, em PostgreSQL, o banco de dados de um banco digital fictício. O sistema cobre contas correntes e poupança (inclusive conjuntas), extrato de movimentações, cartão de crédito e empréstimos parcelados. O repositório traz o ciclo completo: DER, modelo lógico normalizado até a 3FN, scripts DDL e DML, 36 consultas, subconsultas, views, controle de acesso (DCL) e transações (TCL), além de um relatório completo em Word.
